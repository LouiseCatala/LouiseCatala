# Orland Louise Catala

I'm Louise Catala, a Computer Engineering student at Systems Plus College Foundation in the Philippines. I work across software and hardware, building web applications, connecting sensors to embedded devices, and using CAD to explore how physical systems fit together.

I like projects with a practical reason behind them: helping farmers coordinate post-harvest services, turning an existing laptop into a shared touchscreen kiosk, or making computer diagnostics easier to understand.

## What I work on

- **Software development and web development:** interfaces, APIs, and database workflows using React, TypeScript, JavaScript, PHP, Python, MySQL, and Firebase.
- **Embedded systems, IoT, and automation:** Arduino and ESP32 projects that connect sensors, device controls, and web applications.
- **CAD and 3D modeling:** AutoCAD drawings, enclosure concepts, and studies of how components fit into a physical design.
- **Circuits and hardware:** electronics prototypes, KiCad layout studies, and digital logic with Verilog and Logisim.

## Featured engineering projects

### [KAWING — Post-Harvest Coordination Platform](https://github.com/LouiseCatala/KAWING--IoT-Integrated-Post-Harvest-Coordination-Platform)

A web platform connecting farmers, buyers, and post-harvest service providers. It brings together harvest listings, service coordination, and grain moisture readings from the PalaySense device.

### [From Laptop to Kiosk — Acer R11 Touchscreen Transformation](https://github.com/LouiseCatala/From-Laptop-to-Kiosk-The-Acer-R11-Transformation)

Repurposing an Acer Chromebook R11 as a shared access device for KAWING. The repository documents the AutoCAD enclosure concept and Debian touchscreen kiosk configuration, including the limits of the design and configuration snapshot.

### [KAWING PalaySense](https://github.com/LouiseCatala/Kawing-PalaySense)

An ESP32 grain moisture assessment prototype that sends estimated readings to KAWING over Wi-Fi. The documentation covers the hardware connections and the need for calibration against a reference meter.

### [CareWare](https://github.com/LouiseCatala/CareWare)

A Windows PC health-checking application with plain-language diagnostic results, local checkup history, reports, and cleanup tools that require review and consent.

### [e-LINGAP](https://github.com/LouiseCatala/e-LINGAP)

A citizen intake and welfare portal concept built with React, TypeScript, and Firebase, covering applications, appointments, and request tracking.

### [Automatic Parking System](https://github.com/LouiseCatala/Automatic-Parking-System)

An Arduino prototype combining vehicle detection, a servo-operated gate, an LCD slot counter, and automatic lighting.

Other work includes [rain-sensing home automation](https://github.com/LouiseCatala/Smart-Home-Automation-Rain-Sensing-Retractable-Clothesline-and-Automatic-Door-System), [3D AutoCAD house models](https://github.com/LouiseCatala/3D-Floor-Plan), and [Verilog digital logic](https://github.com/LouiseCatala/2to1mux).
